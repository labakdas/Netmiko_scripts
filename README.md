These scripts are used to backup Cisco devices from command prompt of the laptop.
This requires two additional files commands.csv and hostname.csv
These scripts will ask the location of the id_rsa file. 
These scripts will prompt for the location of the devices.csv and hostname.csv
These scripts will prompt for the location to save the backup
The _improved.py file will store the backups in a more meaningfull way. example Show running-config can be saved as running-config within the backup folder. The commands.csv should be modified
